🔗 Muat dari link (Google Sheets / SharePoint) — alternatif upload file · bisa banyak link (satu per baris) ▼
Setiap kotak menerima dua jenis link:
• Google Sheets — link Publish to web → CSV (File → Share → Publish to web → pilih sheet → CSV). Bukan link share biasa.
• SharePoint / OneDrive — link file .xlsx (Share → Anyone with the link). Otomatis diunduh & dibaca (sheet pertama). Link khusus organisasi bisa diblokir browser (CORS) — bila gagal, pakai upload file.
Boleh >1 link per kotak (satu per baris); semua digabung & duplikat dilewati.
